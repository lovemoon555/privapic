# PrivaPic – Private Photo Vault

**PrivaPic** is a secure photo vault app that keeps your private photos protected with a password, Face ID, or Touch ID. All data is stored locally on your device — nothing is uploaded to the cloud.

---

## Features

- Password-protected photo vault
- Face ID & Touch ID support
- Multiple albums to organize photos
- Import from photo library or capture with camera
- Decoy password to hide the app's true purpose
- Auto-lock when switching away from the app
- 100% local storage — no cloud, no tracking

## FAQ

**Q: What happens if I forget my password?**  
A: For security reasons, there is no password recovery. We recommend using a memorable password and enabling Face ID / Touch ID as a backup.

**Q: Can I transfer my photos to a new device?**  
A: Currently, PrivaPic stores data locally and does not support cross-device transfer. This is by design to maximize privacy.

**Q: What is the Decoy Password feature?**  
A: You can set a secondary "decoy" password. When entered, it opens a fake calculator interface instead of the vault, protecting your privacy in sensitive situations.

**Q: Is my data backed up to iCloud?**  
A: No. PrivaPic intentionally excludes iCloud backup for your photos to ensure maximum privacy.
